# augeo-mvp
 WhatsApp-native bot that converts a product photo and a few text details into a professional marketing flyer for Nigerian small-business sellers.

Environment notes:
- `IMAGE_PROVIDER` defaults to `ideogram` (recommended).
- For messaging: configure `KASPO_API_KEY` and `KASPO_BASE_URL` (or wire your preferred gateway). Captions are generated in English by default; users may provide custom caption text.
